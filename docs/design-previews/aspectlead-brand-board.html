Why it works: the skew + facet cut expresses “aspect / viewpoint / angle” inside the type itself — sharp, modern, ownable, distinctly SaaS. The favicon derives from the facet, not an “A”. Risks: skew must stay subtle (≤7°) to keep legibility; a heavier cut could read like an italic gimmick — needs a real type-designer pass to refine the letterforms.

What we learned from dashboard references

Hierarchy first
One dominant surface (the map), a clear command bar, then supporting overlays and dense panels in priority order — instead of a flat grid of equal cards.
Spatial context
A large territory/map canvas is AspectLead's real differentiator. Leading the screen with space, coverage heat and routes reads as territory intelligence, not generic admin.
Glass, only where meaningful
Frosted overlays for spatial/command controls that sit over the map; solid surfaces everywhere reading matters (tables, gate, settings). Blur is controlled, never decorative.
Signal-led controls
Compact switches, segmented toggles and a legend — not a wall of KPI cards or pill badges. Controls express live state, not chrome.
One language, two themes
Light and dark are the same product with swapped tokens — identical layout and data — so the brand holds whichever a user runs.
Experience over tray
The screen should feel like a place you operate from, with map, live run and selection state — not a catalogue of components.

Why this does not smell like a generic dashboard

Instrument, not admin. Compact telemetry density with mono figures and coordinate labels (UB1 · TQ128796 · A4020 CORRIDOR · RUN-0042) — it reads like a territory console, not a CRUD table with hero cards.
Perspective-cut facets. Panels, signal tiles and lead rows carry sliced corners and skewed accent edges taken straight from the Route B wordmark — the logo language is literally built into the chrome, so nothing looks like a stock Tailwind card.
Signals, not KPIs. Every tile has a micro-trend and a signal trace sparkline; leads show signal-strength bars and a territory sliver. The data feels discovered, not merely counted.
No pill spam, no beige alerts. Status lives in a hairline state strip and mono labels; the export blocker is a hazard-railed release checkpoint (ISS-0003 · LOCKED), not a rounded amber banner.
Map DNA everywhere. A contour + coordinate-grid Territory Lens, corridor codes on leads, and a mini territory sliver per row keep the geographic/territory idea present without a full map or any logistics/pin cues.
Action rails, not big buttons. Row actions are compact stacked command rails (Assign / Route / Ignore) — dense and operational, not a scatter of large primary buttons.
Safe-view discipline. Telesales shows only operational counts and rep queues with score/margin/financials explicitly redacted — the UI encodes the RLS safe-view rule, which a generic template never would.
One system, two honest themes. Light uses platinum/white/carbon with text-safe blue/amber and cyan reserved for dots/borders; dark uses midnight/carbon with cyan/blue/violet for live signal and amber only for gates. Same geometry, different tokens — proven side by side.

Design decisions to carry into the app

Theme system
Auto / Light / Dark selector in the command bar and Settings. Auto follows the OS; the user's override is remembered. Both themes are first-class — the app is never dark-only.
Identity
Wordmark-led — AspectLead two-tone. No generic standalone “A” mark anywhere in the product.
Preferred logo
Route B — Perspective Cut: the skewed facet becomes the app's signature accent (panel header ticks, tile edges, sliced corners). See docs/20 refinement brief.
Dark surfaces
Command chrome — rails, command bar, map canvas, live run/telemetry. Midnight/carbon; glow reserved strictly for live/signal elements.
Light surfaces
Work chrome — tables, forms, review, export. Platinum/white/carbon; cyan only as dots/borders/icons, never body text.
Map / territory
Territory Lens is a signature component: contour + coordinate grid, postcode/grid refs (UB1 · TQ128796), corridor codes (A4020). Abstract — never pins/vans/logistics cues.
Signal tiles
Compact telemetry — one label, mono figure, micro-trend, signal-trace sparkline, territory code. Never big soft KPI cards.
Export gate
A controlled release checkpoint: hazard-rail, issue code (ISS-0003), LOCKED state, manual-verify action. Never a rounded beige alert.
Safe telesales
Restricted v_telesales view: operational counts + rep queues only. Score, margin and financials explicitly redacted — the UI encodes the RLS safe-view rule.

These are direction only — nothing here is implemented in the app, finalised, or legally cleared.
