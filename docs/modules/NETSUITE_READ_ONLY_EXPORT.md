# NetSuite Read-Only Export

## Purpose

NetSuite is the source of truth for existing customer master records used in deduplication.

## Required fields

- Account code
- Business name
- Trading address
- Postcode
- Phone numbers
- Customer status active/inactive
- Average weekly spend
- Order count
- First order date
- Last order date
- Acquisition channel where available
- Sales rep where available

## Rule

Read-only for this project. No NetSuite writes in MVP.
