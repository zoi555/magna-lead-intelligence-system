# Manual Test Protocol

Before any automated volume run, run one business manually end to end.

## Steps

1. Find business on platform.
2. Confirm address and postcode.
3. Check active/inactive customer match.
4. Match FSA by address.
5. Check Companies House by address/operator.
6. Capture phone/contact source.
7. Calculate score.
8. Decide route: export, ignore, reactivation, expansion, manual review.
9. Record evidence.

## Pass condition

The process must be clear enough to complete manually in under 10 minutes per business.
